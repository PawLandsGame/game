# Инструкции для работы с PawLands

## Коммиты и публикация

- После проверки каждой завершённой задачи создай отдельный коммит и сразу отправь его в `origin` в текущую рабочую ветку. Не объединяй независимые задачи в один коммит.
- Используй формат Conventional Commits `тип(область): описание`. Область необязательна. Тип пиши стандартным английским токеном (`feat`, `fix`, `docs`, `chore`), а описание и тело коммита пиши на русском языке.
- Включай в коммит только изменения, относящиеся к задаче. Если пользователь указал другую ветку или попросил отложить публикацию, следуй его указанию.

Пример: `fix(клиент): дождаться подключения перед входом в игру`.
